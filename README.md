# Held to the End

*Held to the End* is an original Christian contemplative work by Michael Collins exploring mortality, death, resurrection, judgment, and life everlasting. Written for readers carrying grief, fear, or unanswered questions, it considers judgment as truth serving healing and invites hope in the restoration of all things. Drawing on Scripture and human experience, the book offers trust in the love revealed in Christ while remaining humble before the mysteries of the life to come.

This is an original work, not a retelling or translation of an earlier source.
